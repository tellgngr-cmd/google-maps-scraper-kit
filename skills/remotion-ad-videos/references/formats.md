# Platform formats

| format | size | use for |
|---|---|---|
| vertical | 1080×1920 (9:16) | TikTok, Instagram Reels & Stories, YouTube Shorts, Facebook Reels, Snapchat |
| portrait | 1080×1350 (4:5) | Instagram & Facebook feed (takes the most feed space) |
| square | 1080×1080 (1:1) | Feed posts, LinkedIn feed, X |
| landscape | 1920×1080 (16:9) | YouTube in-stream, LinkedIn video, website hero, X |

**Length guide:** TikTok/Reels 9–15s · Stories 6–15s · Feed 10–20s · YouTube in-stream 15–30s
(first 5s must carry the hook, since viewers can skip) · LinkedIn 15–30s.

**Safe zones:** on vertical, platform UI covers roughly the top 10% and bottom 20%, so the
template keeps text centred. Don't move key text to the edges.

When the user names a platform, pick the format; when they say "all platforms", render
vertical + portrait + landscape of the same copy.
